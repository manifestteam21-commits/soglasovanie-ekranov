# Согласование экранов

Три согласованных цветовых решения первого экрана сайта Светланы Пшонкиной:

- Вариант 1 — сине-зелёный, #246D75.
- Вариант 2 — винный, #7C3045.
- Вариант 3 — синий, #2B5D9A.

Главная страница index.html позволяет переключать варианты. Прямая ссылка на вкладку: #variant-1, #variant-2 или #variant-3. «Открыть отдельно» показывает выбранный макет без панели сравнения.

Внутренние страницы демонстрационные. Исходные макеты, тексты, фото результатов и интерактивность сохранены.

Статический сайт без сборки и внешних зависимостей. Для GitHub Pages: branch main, folder / (root). Для локального просмотра откройте index.html.

Фото и оформление предоставлены для согласования проекта. Лицензии локальных шрифтов сохранены в папках assets.
